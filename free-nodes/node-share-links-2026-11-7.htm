第一章：重新认识Quantumult脚本——它究竟在做什么？

在深入代码之前，我们必须建立清晰的认知：Quantumult脚本并非传统意义上的编程语言，而是一种事件驱动的规则引擎。它监听网络请求的生命周期，在特定节点（如请求发起、响应返回）触发你预设的逻辑。你可以把它想象成一个智能交通警察——每辆“网络请求”的车辆经过路口时，脚本决定是放行、改道、还是直接拦截。

这种设计哲学带来了三大核心优势： 1. 动态决策：基于请求头、URL、响应体等实时数据做出判断，而非静态规则 2. 资源优化：在设备端完成数据处理，减少不必要的流量消耗 3. 个性化定制：每个用户都能编写属于自己的“网络宪法”

第四章：调试与优化——让脚本稳定运行的必修课

4.1 日志的艺术：善用console.log

Quantumult提供了完善的日志系统，但错误的使用方式会导致调试效率低下。建议遵循以下原则： - 分级输出：用console.log记录正常流程，console.error标记异常 - 关键节点必打：请求进入、条件分支、返回结果处 - 避免冗余：不要每行代码都输出，聚焦于变量变化和决策点

4.2 性能优化：减少脚本对网络的影响

脚本运行在代理网络中，任何延迟都会被用户感知。优化建议： - 避免同步阻塞：不要使用while循环等待异步操作 - 精简正则表达式：复杂正则会导致CPU飙升，可预编译缓存 - 复用全局变量：将常用配置存放在$prefs中，避免重复计算

4.3 异常处理：让脚本在错误中优雅降级

网络环境千变万化，脚本必须拥抱异常：

javascript try { // 可能出错的操作 const data = JSON.parse($response.body); // ... 处理逻辑 } catch (e) { // 出错时返回原始响应，保证功能可用 console.error("解析失败: " + e.message); $done($response); }

第六章：常见错误与规避策略——从踩坑到填坑

错误一：忘记调用$done()导致请求挂起

解决方案：始终保证脚本所有路径都能执行$done()，建议在函数末尾统一处理。

错误二：正则表达式过于宽泛导致误匹配

解决方案：用^和$锚定边界，尽量使用非贪婪匹配，并配合URL结构限定范围。

错误三：修改请求体但未更新Content-Length

解决方案：修改body后，同步更新headers中的Content-Length字段，否则服务器会报错。

错误四：异步操作未正确处理

解决方案：使用async/await或Promise链，确保$done()在异步操作完成后调用。

FAQ

Sing-box 的 DNS 模块如何工作？
Sing-box 内置 DNS 模块，支持 fake-ip 模式和纯直连模式。它可根据规则选择不同的上游 DNS 服务，从而实现国内外域名智能分流，减少访问延迟。
VMess 的 WebSocket + TLS 配置有哪些好处？
WebSocket + TLS 可伪装为普通 HTTPS 流量，增强抗封锁能力和隐蔽性。结合域名伪装和策略组使用，可以在高封锁网络中保持稳定、高速和安全的网络访问体验。
V2Ray 的路由规则如何实现按应用分流？
V2Ray 支持按用户标签或端口匹配应用流量，结合策略组可实现指定应用走特定节点。这样可以保证游戏、视频和浏览器流量各自走最优线路，提高访问效率。
V2Ray QUIC 传输适合什么网络环境？
QUIC 基于 UDP 支持多路复用和零握手，降低延迟，提高吞吐量。适合高丢包、不稳定网络环境，可保证视频、游戏和即时通讯流量的稳定性和流畅体验。
SSR 的协议插件如何增强连接稳定性？
SSR 的协议插件可以增加流量的伪装特性，模拟常见协议或浏览器行为，从而降低被识别和封锁的风险。这对不稳定网络或高封锁环境尤其有帮助。
Hiddify Next 如何实现用户流量分配？
管理员可为每个用户设置带宽和流量配额。超出限制时可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和效率。
Mellow 是否支持 IPv6 流量代理？
Mellow 支持 IPv6，只需在配置文件中启用 IPv6 DNS 解析并确认操作系统开启 IPv6 路由功能。部分节点若不支持 IPv6，则相关请求会自动回退到 IPv4，保证兼容性。
Matsuri 支持订阅更新吗？
支持。Matsuri 内置订阅更新模块，可自动检测链接变化并定期刷新节点。用户还可手动点击更新按钮同步最新配置，保持网络连接的可用性与速度。
Sing-box 如何精确匹配端口流量？
Sing-box 支持按端口设置流量分流规则，将不同类型流量分配到不同节点。结合策略组使用，可提高访问速度和稳定性，实现精准流量管理和优化网络体验。
V2Ray 如何通过策略组优化访问速度？
策略组允许用户将节点按延迟、地域或用途分组。结合路由规则，V2Ray 会自动选择最优节点处理流量，提升访问速度并降低延迟，尤其在访问海外网站时效果明显。
